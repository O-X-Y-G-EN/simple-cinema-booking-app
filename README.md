# 🍿 Simple Cinema Ticket Booking App

This is a basic GUI application for reserving cinema tickets, built using Python's built-in Tkinter library.

## Features
* Select from a list of available movies.
* Dynamically update available seats.
* Confirmation and pricing display.

## How to Run
1.  Ensure you have Python 3 installed.
2.  Run the application from your terminal:
    ```bash
    python CinemaBookingApp.py
    ```
